# Проверка сайта

1. Открой указанный адрес через Playwright. Если доступны инструменты Playwright MCP — используй их.
   Иначе запусти скрипт из папки этого skill:
   ```
   node .claude/skills/check-site/check.js <адрес> <scratchpad>/site.png
   ```
   (если нет `node_modules` — сначала `npm install` в папке skill). Скрипт выводит JSON:
   статус ответа, заголовок, ошибки консоли и JS, неудачные запросы, ссылки, кнопки
   и элементы без подписей. Посмотри скриншот, чтобы описать страницу визуально.
2. Проверь:
   - страница загрузилась без ошибок (статус 2xx, нет `loadError`, нет неудачных запросов);
   - все кнопки и ссылки имеют понятные подписи (нет пустых и невнятных вроде «тут», «click»);
   - в консоли браузера нет ошибок.
3. Кратко опиши результат по-русски: что работает, что нет.
4. Если нашлись проблемы — спроси меня, создать ли issue в текущем репозитории на GitHub.
   Если да — создай issue через GitHub MCP или `gh issue create`
   с заголовком «Проблемы на странице: <адрес>» и списком найденного.
   Если текущая папка не git-репозиторий, спроси, в каком репозитории создать issue (`gh issue create -R владелец/репо`).
